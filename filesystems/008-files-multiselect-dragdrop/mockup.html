Files — Multi-Selection & Drag-and-Drop

UI mockup for the spec-kit design step · builtin-app at src/apps/files/ · visual proxy for the shipped React app (no build step). Every panel is mapped to a user story (US badge, top-right) and a requirement.

US1 · Select multiple items US2 · Context menu on the selection US3 · Drag & drop, within + across instances Mirrors the Files app palette, toolbar & context-menu ⌘ = macOS · Ctrl = Windows

US1 — Multi-selection

FR-001 · FR-002 · FR-003 · FR-004 · FR-005 · FR-014

One folder, fourteen items. Each panel shows a distinct selection state in the same list so the states can be compared at a glance. A selection chip in the toolbar always names the active set.

US2 — Context menu on the whole selection

FR-006 · FR-007 · FR-013

The right-click menu acts on the entire selection, and its enabled/disabled set depends on the selection: batch actions stay available, single-only actions (Rename, Open) grey out for >1 item. No regression for the one-item case.

US3 — Drag-and-drop to move or copy

FR-008 · FR-009 · FR-010 · FR-011 · FR-012 · FR-015 · FR-016

A drag that begins on an item moves/copies; a drag that begins on empty space is the US1 marquee — the two never conflict. A ghost with a count badge follows the cursor; a folder row lights up as the drop target. Cross-instance is shown as one continuous scene across two Files windows over the shared VFS.
