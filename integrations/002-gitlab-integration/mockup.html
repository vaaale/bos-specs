Agent that handles new issues

A normal agent (Settings → Agents). Its skill defines the pipeline — classify (Bug / Feature / Improvement) → run the matching workflow → apply status labels → end at Needs Review. The agent performs all GitLab operations via its configured GitLab MCP server (no credential is stored in BOS).

A built-in gitlab-issue-triage handler is enabled by default — it forwards each new issue to the agent above. Toggle it in the Events handler configuration to stop auto-processing, or point another consumer (e.g. the Workflow app) at the gitlab.issue.opened event instead.
