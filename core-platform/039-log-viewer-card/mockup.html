Decisions locked in the mockupDesign
Interaction
Native <details> per row → multi-open + focusable + Enter/Space for free; no React state, no pruning.
Shared card
One LogRecordCard component is the expanded body for both surfaces; Settings' inline body is migrated to it.
Stable keys
Rows keyed by a stable record id (hash of ts+stream+component+msg when no id) so an open card survives the 4s re-sort.
Sizing
Toolbar list max-h 340→440px, width 900px unchanged; Settings stays flex-1.
Capped scroll
Huge err.stack / data render in height-capped scrollable regions — one record can't blow up the panel.
Theme & copy
Built from existing tokens (level colours, stream badges, border-white/10, font-mono); Copy JSON reuses the context-menu copyToClipboard.
