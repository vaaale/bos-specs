Spec 036 · file-type-handlers · UI mockup

"Open with" in the Files context menu

The only new user-facing UI in this feature. Right-clicking a file surfaces one Open with <App> row per app registered as a handler for the file's MIME type (FR-008). The row carrying a check is the currently-selected default used by double-click; picking an unchecked row opens the file there now and makes it the new default (FR-010, "always open with").

Note (FR-010, Option A). The checkmark marks the handler currently selected as the default for text/html — the one double-click uses. Picking an unchecked "Open with" entry opens the file in that app right now and makes it the new default (macOS "always open with"). Hidden handler apps (Web View) appear by their own label even though they have no dock icon. Each row's icon is the target app's own manifest icon (never a semantic glyph): "Web View" shows html-viewer's Code2 glyph; "Editor" carries a placeholder pen here that will be the Editor's own manifest icon at runtime.
