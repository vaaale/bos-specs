Fix Spec-Tree Deletion in Build Studio

user-specs/build-studio/052-spec-tree-delete/spec.md

Right-click a spec item in the left treeview → Delete → confirm. The deletion does not complete and the same warning box is shown again. Also, right-clicking the folders must offer a working Delete.

Why it matters

Today the confirmation dialog only closes on a successful delete. When the delete is refused, the box stays open, appends the error, and re-fires the identical request on every Ok — the "same warning box reappears" loop. Separately, plain folders have no right-click menu at all.

What changes

1 — A failed delete of any kind closes the dialog and shows the reason once in a banner. 2 — Every writable container (project / dir / feature) gets a Delete… menu, with a count of what will be removed.
